# 今晚吃什么？

把晚饭选择困难变成一局轻松的美食抽签。按下 OK，看分类和食物依次滚动，
让 12 类、60 种美食替你回答今晚的问题。

![AI 生成的玩法示意插画](assets/images/tonight-dinner-cover.png)

封面为 AI 生成的玩法示意插画，并非实机截图。

## 怎么玩

- 上/下键选择，OK 短按确认，长按返回。
- 开始抽取，选择“就它了”或者再抽一次。连续重抽会遇见调皮的小彩蛋。
- 随便吃、省钱、清淡、重口、聚餐五种模式可选；按预算、忌口和不喜欢的
  食物缩小范围，设置自动保存。
- 薯条、笑脸汉堡、饮料杯和皇冠雪人为你加油。

完全离线，几秒钟结束纠结。详细操作见[玩法说明](docs/dinner.zh_CN.md)，
已验证的行为见[验收报告](docs/dinner-validation.zh_CN.md)。

## 固件与源码

初始版本为 `1.1.0-dinner`。固件校验、刷入与构建方法见[发布说明](docs/dinner-release.zh_CN.md)。

基于官方 [FoloToy AI Passport](https://github.com/FoloToy/ai-passport) 项目，
应用实现了独立的晚饭抽签界面。
